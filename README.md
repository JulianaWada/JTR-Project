# Jules TechRight website

Official website for Jules TechRight (JTR). Next.js (App Router) + TypeScript + Tailwind CSS + next-intl.

> Work in progress. Full setup, content-editing and deployment docs are added in the final stage.

```bash
npm install
cp .env.example .env.local   # then fill in the keys
npm run dev                  # http://localhost:3000
```
